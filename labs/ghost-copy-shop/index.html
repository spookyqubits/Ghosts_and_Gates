Run an audit

Each machine claims to make two perfect copies of any input. Find one preparation and measurement where the machine’s output probabilities differ from two ideal copies. Use Z for |0⟩ or |1⟩, and X for |+⟩ or |−⟩, or test in the other basis.

College lab questions

Try an input and a measurement that the controlled copier gets right. Then change the input to |+⟩ and measure both outputs in X. Compare all four possible pairs of answers with the table for two independently prepared copies. Which pair of answers gives the copier away?

Why can the machine copy two states that you can tell apart with certainty, such as |0⟩ and |1⟩, and give a different result for their superposition?

Model and experiment

Start with a fresh input and a target in |0⟩. The controlled copier uses CNOT. The transfer machine swaps the input and target. The X-basis copier measures in X and makes two states from its reading. The reference column shows what you’d see with two fresh preparations of the input.

CNOT can copy |0⟩ and |1⟩. Because the gate is linear, a superposition of those two inputs becomes an entangled pair. Two actual copies would be independent. You can use the measurement table to see the difference. One failed test is enough to rule out a machine that claims to copy every state.
