      Model and experiment

      Each hop uses one pair and sends the two bits from a Bell measurement. The first bit calls for Z and the second for X. A wrong correction changes how the sealed state is carried forward. The debrief uses the simulator’s hidden state to compute fidelity.

      A fast hop has an independent 5% erasure chance. A checked hop is ideal in this classroom model. All-fast survival is 0.95⁵ ≈ 77.4% before correction errors. This game models an erasure flag for a lost state. Real hardware can have additional errors. Hermans et al., teleportation across a network
