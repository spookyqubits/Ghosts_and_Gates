      College lab questions

      Ask questions involving several voices. Find a question whose answer is implied by earlier answers. Why does it increase the query count without increasing the number of independent answers? Try five and eight voices.

      Explain how the oracle’s amplitude pairs (+,+) and (+,−) become 0 or 1 after H. Compare an exact recovery with a correct guess made while some bits were undetermined.

      Model and experiment

      The Bernstein–Vazirani oracle evaluates the bitwise dot product x · s modulo 2. One coherent query marks amplitude x with sign (−1)x · s. This phase pattern factors into one amplitude pair per voice. The display computes this exact ideal model. A Hadamard on each voice then recovers the hidden string with certainty.

      Each independent classical parity answer gives at most one bit of information about an arbitrary N-bit secret. Exact classical recovery needs N independent answers in the worst case. The game counts oracle calls separately from preparation, gates and readout. Bernstein and Vazirani, Quantum Complexity Theory
