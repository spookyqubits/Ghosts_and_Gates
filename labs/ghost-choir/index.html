Recover a hidden bit string using classical questions and a simulated quantum oracle.

    Find the hidden pattern

    A classical query here sets a single input bit to 1. You can compare that with one coherent query to the same parity oracle.

    College lab questions

    Explain why the response to the classical input with only bit i set is exactly secret bit i. Then start a new secret and run the coherent query. Explain how the signs introduced by the oracle turn into bits after the last H gates.

    Model and experiment

    The Bernstein–Vazirani oracle evaluates the bitwise dot product x · s modulo 2. One coherent query marks amplitude x with sign (−1)x · s. This particular phase pattern factors across the voices, so a Hadamard on each voice returns the hidden string with certainty in the ideal model.

    Each independent classical parity answer gives at most one bit of information about an arbitrary N-bit secret, so exact classical recovery needs N such queries in the worst case. The game counts oracle calls and treats preparation, gates, hardware, and readout as separate operations. Bernstein and Vazirani, Quantum Complexity Theory
